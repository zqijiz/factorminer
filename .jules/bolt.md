## 2023-10-27 - Vectorizing Cross-sectional Financial Metrics
**Learning:** Python loops over the time dimension (e.g. `for t in range(T)`) for operations like rank and correlation on cross-sectional financial matrices shape `(M, T)` are a massive performance bottleneck. The `scipy.stats.rankdata(..., axis=0, nan_policy='omit')` operation is much more efficient on the entire array, speeding up standard evaluations by 1.5x-2x. Similarly, vectorized assignments into groups (quintiles) via ranks (`np.ceil(ranks / valid_count * n_quantiles)`) combined with masked operations (`np.where`, `np.nansum`) offer identical output dynamically across multiple time steps in one pass. It also avoids `RuntimeWarning` exceptions correctly through safe divide checks.
**Action:** When implementing factor metrics calculating values strictly cross-sectionally per period, always attempt to reshape the operation as vector multiplications and summations across `axis=0` utilizing `rankdata`, completely avoiding explicit `range(T)` loops.
