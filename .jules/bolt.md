## 2025-05-20 - Vectorized Cross-Sectional Ranking
**Learning:** Cross-sectional financial time-series ranking and quantile binning in numpy using Python `for t in range(T)` loops combined with `np.argsort().argsort()` introduces a massive O(N^2) overhead bottleneck because `.argsort()` must be independently called for every time slice. The fully vectorized equivalent relies on `scipy.stats.rankdata(method='average', axis=0, nan_policy='omit')` across the `(M, T)` array, achieving a greater than 2x performance speedup while maintaining mathematical correctness for ties.
**Action:** When calculating cross-sectional or rolling ranks (and extending that logic to quantile binning) in a numpy matrix where `axis=0` is asset and `axis=1` is time, always use fully vectorized `scipy.stats.rankdata(..., axis=0)` with dynamic matrix normalization arrays (`valid_counts = ~np.isnan(x); n = valid_counts.sum(axis=0, keepdims=True); (ranks - 1.0) / (n - 1.0)`) instead of explicit temporal python loops.
