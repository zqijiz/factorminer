## 2024-06-09 - Pre-calculating rolling window operations outside loop speeds up PyTorch algorithms drastically
**Learning:** In sequential time series algorithms (like KAMA) where element t depends on element t-1, we can't fully vectorize the time loop. However, replacing boolean slice indexing assignments inside the loop with branchless `torch.where` AND pre-calculating rolling operations like volatility using `.diff().unfold(dim, window, step).nansum()` outside the loop speeds up the calculation significantly because it avoids creating multiple small kernels and host-device synchronizations within the tight loop.
**Action:** When implementing algorithms like EMA or KAMA in PyTorch, calculate whatever you can outside the loop using `unfold` or `cumsum` and use `torch.where` for sequential assignments.
