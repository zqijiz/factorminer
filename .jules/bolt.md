## 2024-06-25 - [Vectorized Ranking Optimization in Portfolio Backtester]
**Learning:** Cross-sectional financial time-series ranking and quantile binning can be optimally vectorized across the 2D array while perfectly matching mathematical expectations. While `np.argsort(x, axis=1).argsort(axis=1)` handles missing values well and is extremely fast, it fundamentally breaks the correctness of quantile backtests by assigning unique ordinal ranks to tied signal values (thereby splitting identical signals randomly into different bins). `scipy.stats.rankdata(method='average', axis=1, nan_policy='omit')` is the correct solution. It properly handles ties and is still an order of magnitude faster than iterating cross-sectionally in a Python `while` loop.
**Action:** Never use `np.argsort().argsort()` as a replacement for rank calculations in financial data where signals may have identical values (ties), as it alters the mathematical correctness. Always rely on `scipy.stats.rankdata(..., method='average', axis=1, nan_policy='omit')` to correctly vectorize 2D ranking.
