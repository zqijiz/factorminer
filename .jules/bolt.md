## 2023-10-25 - Scipy Vectorization over Loops for Array Ranking
**Learning:** In cross-sectional arrays where the time axis (T) is long and the asset axis (M) has missing data (NaNs), computing rank/quantiles manually inside a loop is extremely slow. Scipy's `rankdata(..., axis=0, nan_policy='omit', method='ordinal')` executes the entire matrix ranking in C/Cython quickly. The surprising insight was that we must post-process `rankdata` to restore backward-compatible behavior: `nan_policy='omit'` handles NaNs correctly but we still need to calculate valid item counts per column to manually zero-out columns with `< 2` valid items, which otherwise might falsely produce a 0/0 valid rank.
**Action:** Always favor vectorization in Python/NumPy for cross-sectional operations, specifically utilizing `scipy.stats.rankdata` rather than `np.argsort` looping when dealing with complex missing-data policies. Ensure edge cases like insufficient data count are reapplied post-vectorization.
