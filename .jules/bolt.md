## 2024-04-30 - Vectorized Cross-Sectional Ranking
**Learning:** Cross-sectional percentile ranking and quantile binning can be huge performance bottlenecks when iterating through columns manually (`for t in range(T)`). A fully vectorized approach using `x.argsort(axis=0).argsort(axis=0).astype(np.float64)` is highly effective for financial time-series data. It natively handles tie-breaking behavior, automatically sorts NaNs to the end, and correctly mirrors the original pandas-like ranking without adding `scipy` dependencies.
**Action:** When working with 2D financial time series matrices (Assets x Time), aggressively refactor cross-sectional python loops into double-argsort vectorization, ensuring proper NaN masking via `~np.isnan(x)` and safe divisions via `np.errstate`.
