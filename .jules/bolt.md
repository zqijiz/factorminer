## 2024-06-26 - [Branchless Updates in Sequential Time Series Algorithms]
**Learning:** In sequential time series algorithms (like EMA) where element t depends on element t-1, we can't fully vectorize the time loop. However, replacing boolean slice indexing assignments (e.g., `out[mask, t] = ...`) inside the loop with branchless `np.where` (or `torch.where`) assignments to `out[:, t]` avoids creating expensive intermediate arrays in NumPy and reduces severe host-device synchronization overhead in PyTorch. This simple rewrite can speed up the tight loop by 25-35%.
**Action:** Whenever a time series algorithm necessitates a Python-level sequential loop, prefer using branchless operations on the entire slice (like `out[:, t] = np.where(valid, update, out[:, t])`) instead of conditional indexing (`out[valid, t] = update[valid]`) to minimize allocation and synchronization penalties.
