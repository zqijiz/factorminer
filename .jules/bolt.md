## 2024-05-24 - Pure Numpy Vectorization for Cross-Sectional Ranking
**Learning:** In the `factorminer` codebase, financial time-series operations over cross-sections with many missing values (e.g., `(3000, 2000)` matrices) present a significant performance bottleneck when processed column-by-column using Python loops. Even with `numpy` primitives inside the loop, the Python overhead dominates.
**Action:** Replace iterative cross-sectional loops with pure vectorized `numpy` operations. Specifically for ranking, `x.argsort(axis=0).argsort(axis=0).astype(np.float64)` computes ranks across all columns simultaneously, cleanly handling `np.nan` values (which are naturally sorted to the end). Using a combined `valid_counts = (~np.isnan(x)).sum(axis=0)` mask properly sets values with inadequate observations back to `np.nan` and adjusts normalization denominators.
