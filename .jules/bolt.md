## 2025-02-12 - Vectorize Cross-Sectional Ranking and Correlation Loops
**Learning:** In `factorminer/evaluation/correlation.py`, the spearman cross-sectional evaluation bottlenecked on a combination of Python iteration over time dimensions using `scipy.stats.rankdata` internally, and secondary nested loops that repeatedly performed mean aggregation, subtraction, multiplication, array squaring, and square roots. By shifting to completely vectorised Operations with Pandas Rank functionality `pd.DataFrame(x).rank(axis=0).values` (which also resolves NaNs accurately on `method=average` by default without the overhead seen in scipy) and converting iterations into `axis=0` aggregates `(np.nanmean, np.sum(axis=0))` the 3 rank-based algorithms perform up to 5x faster.
**Action:** Replace 1D `scipy.stats.rankdata` loop with 2D `pd.DataFrame(x).rank()` calls, and refactor tight sequential correlations across the T dimension into bulk `np.nanmean`, `np.where`, `np.divide` instructions using valid logic masking to remove the sequential iteration.
