
## 2024-05-18 - Optimize Kaufman Adaptive Moving Average (KAMA) rolling sums
**Learning:** In sequential time series algorithms (like KAMA) where element t depends on element t-1, we can't fully vectorize the time loop. However, performing `nansum(diff(..., axis=1))` inside the loop is computationally expensive as it recalculates differences and sums on every iteration. Replacing this with an O(1) cumsum trick — using padded absolute differences via `np.concatenate([np.zeros(...), np.cumsum(np.nan_to_num(np.diff(...)), axis=1)], axis=1)` — avoids repetitive operations and yields massive performance gains. Furthermore, combining this with branchless assignments (`np.where(valid, ..., out[:, t])` instead of boolean slice indexing `out[valid, t]`) eliminates expensive array intermediate allocations. PyTorch also benefits immensely from branchless assignments, as slice indexing forces expensive host-device synchronizations.
**Action:** Always push aggregations (like rolling diffs/sums) outside of sequential loops using the `cumsum` padding trick. Inside sequential loops, favor branchless operations (`np.where`, `torch.where`) over boolean slice indexing to prevent memory allocations and CPU/GPU sync overhead.
