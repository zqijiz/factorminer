## 2024-06-03 - Vectorizing Turnover Computation with np.intersect1d
**Learning:** When computing portfolio turnover or cross-sectional overlap over time, iterating over periods and doing native Python `set` intersections (`len(set_a & set_b)`) on row slices of an array is extremely slow. We can push this entirely into C/NumPy by doing a vectorized `np.argpartition(..., axis=0)` to extract the top K indices for *all* periods at once. Because we are looking for intersection sizes over the time axis, sorting the column slices (`top_indices.sort(axis=0)`) and using `np.intersect1d(..., assume_unique=True)` provides a massive speedup (e.g. ~1.5x - 1.7x) compared to Python-level loops. Attempting to use `np.isin` was slightly slower than `np.intersect1d` in this specific setup where both arrays are already sorted unique integers.
**Action:** When asked to optimize overlap, similarity, or turnover metrics across the time dimension `T`, always prefer doing one large cross-sectional `axis=0` partitioning operation. Then, exploit the fact that arrays are sorted and unique by using `np.intersect1d(assume_unique=True)` for column comparisons to bypass Python iteration overhead.
