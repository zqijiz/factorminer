## 2024-05-01 - Vectorizing cross-sectional ranking with pure NumPy
**Learning:** In factor evaluation, computing cross-sectional ranks and quantiles across large arrays of shape (M, T) via explicit iteration along the time dimension T causes a significant Python loop bottleneck.
**Action:** Replace `for t in range(T)` loops with pure NumPy vectorization `x.argsort(axis=0).argsort(axis=0).astype(np.float64)`. The `argsort` function natively sorts `np.nan` values to the end of the array, and setting the valid count properly per column enables branchless operations. We must mask out elements that were originally `np.nan` and columns with `< 2` valid items at the end to match original behavior. Wrapping the division in `with np.errstate(divide='ignore', invalid='ignore'):` ensures we don't spam runtime warnings.
