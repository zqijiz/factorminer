## 2024-05-30 - Vectorize Cross-Sectional Operations
**Learning:** For 2D cross-sectional ranking with tie-handling across time dimensions (shape M x T), looping with Python (`for t in range(T)`) over NumPy arrays or `scipy.stats.rankdata(nan_policy='omit')` introduces severe overhead. We found that utilizing `pandas.DataFrame(x).rank(method='average', na_option='keep')` correctly preserves average tie semantics while being fully vectorized, resulting in a ~2.5x speedup. For quantile binning where strict mathematical average ties are not strictly required, a fully vectorized double-argsort (`x.argsort(axis=0).argsort(axis=0)`) gives the best raw performance.
**Action:** When implementing cross-sectional evaluation operators over large multi-dimensional arrays, never use a Python-level time loop `for t in range(T)`. Default to `pandas` vectorized ranking for robust tie handling and `np.argsort` vectorization for simple ordinal sorting.
