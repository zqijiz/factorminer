## 2025-02-28 - Fast Vectorized Spearman Rankings
**Learning:** For calculating 2D cross-sectional metrics over time like Spearman pairwise correlation or batch correlation across factor libraries, looping over `scipy.stats.rankdata(..., axis=0, nan_policy='omit')` is a severe bottleneck. The memory states: `scipy.stats.rankdata` introduces severe overhead on large 2D arrays, and using `pandas.DataFrame(x).rank(method='average', na_option='keep')` is fully vectorized and ~2.5-5x faster.
**Action:** When computing cross-sectional correlations over time with NaN handling, use Pandas for the initial rank computation, then vectorize the covariance/variance over time using `np.nansum(..., axis=0)` along with Safe Division (`np.divide(where=...)`). Always apply boolean masks or counts over columns *after* standard numeric allocations to avoid overwrite issues.
