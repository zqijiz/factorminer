## 2023-11-20 - [Operator Vectorization]
**Learning:** Vectorizing cross-sectional ranking across time with `argsort(axis=0)` provides a substantial speedup over iterating through columns (`for t in range(T)`). In addition, using `np.divide` with `where` and `out` provides better speedups for time series return operators than explicit boolean masking which allocates intermediate arrays. Similar logic applies to PyTorch implementations using `torch.where`.
**Action:** When working on operators, look for slow loops iterating over the time dimension and explicit intermediate boolean indexing. Replace loops with fully vectorized operations like `argsort` along the asset axis, and use branchless assignments like `np.divide` and `torch.where` to avoid memory allocation overhead.
