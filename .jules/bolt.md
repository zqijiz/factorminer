## 2025-07-04 - [Optimize KAMA sequential time loop]
**Learning:** In sequential time series algorithms (like KAMA) where element t depends on element t-1, we can't fully vectorize the time loop. However, moving fixed-window aggregation (sum of absolute diffs) entirely outside the loop via a cumulative sum on nan-filled arrays avoids repeated slice aggregation calls. Inside the sequential loop, using `np.divide(..., where=...)` for NumPy and `torch.where` for PyTorch prevents expensive boolean slice assignment overhead inside the loop. This gave an overall 40% performance improvement.
**Action:** Always extract aggregations out of sequential time loops using prefix sums. Use `where` branchless logic instead of explicit boolean masks to update sequential variables to prevent CPU-GPU syncs in PyTorch and array recreation in NumPy.
