## 2023-10-25 - [Smoothing Operators Vectorization]
**Learning:** In sequential time series algorithms (like EMA and KAMA) where element t depends on element t-1, we can't fully vectorize the time loop. However, replacing boolean slice indexing assignments (e.g., `out[valid, t] = ...`) inside the loop with branchless `np.where(valid, ..., out[:, t])` avoids creating expensive intermediate arrays and speeds up the tight loop by 25-30%. Furthermore, intermediate aggregations (like sum of rolling window differences) can be extracted outside the time loop entirely using `np.nancumsum`.
**Action:** When forced to use a time loop for sequential algorithms, always push aggregations (sum, std, max) outside the loop using `np.nancumsum` or rolling views, and use branchless `np.where` instead of boolean masking for element-wise conditional assignments inside the loop.
