## 2025-02-18 - Vectorized Cross-Sectional Ranking and Correlation is 2x Faster
**Learning:** Cross-sectional financial time-series ranking and quantile binning in `factorminer` must use fully vectorized `scipy.stats.rankdata(method='average', axis=0, nan_policy='omit')` rather than Python loops iterating over `np.argsort().argsort()`. This avoids loop overhead and dynamically masks valid values. Rank correlations can then be fully vectorized by computing `cov / sqrt(var_x * var_y)` across all timestamps simultaneously, yielding 2-3x speedups for IC and correlation metrics compared to standard Python loops over `T`.
**Action:** Replace `T`-based loops in metrics like `compute_ic`, `compute_ic_vectorized` and `compute_pairwise_correlation` with fully vectorized implementations. Apply `rankdata` directly with `axis=0`.
## 2025-02-18 - Missing Data Array Masking Precedence (Vectorization Edge Case)
**Learning:** When vectorizing conditional array assignments over NaNs (like in cross-sectional `rankdata` outputs), the assignment order is critical. For example, if both `valid_count < 5` (which should output `NaN`) and `variance == 0` (which should output `0.0`) are true for a column, the condition that sets `NaN` must run *last*. Otherwise, it will overwrite the `NaN` mask with `0.0`, changing the mathematical semantics (a skipped period vs. a zero-correlation period), breaking things like `np.nanmean`.
**Action:** When creating zero-denominators constraints and minimum element masks over NumPy arrays simultaneously, always apply the scalar numeric fill (e.g., `[denom < 1e-12] = 0.0`) *before* applying the missing data mask (`[valid_count < n] = np.nan`).
